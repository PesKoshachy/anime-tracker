# Anime tracker

Аниме-доска на GitHub Pages. Одна общая коллекция в Supabase, без регистрации и входа, по явному выбору владельца. Любой посетитель может читать и изменять коллекцию.

## Хранение

Таблица `anime_shared_collections`, единственная запись `main`. Публичному клиенту разрешены SELECT и UPDATE только столбца payload. Создание/удаление строки, изменение ID, ревизии и служебных полей запрещены. RLS ограничивает доступ общей записью. Старые таблицы аккаунтов сохраняют свои прежние правила доступа.

При открытии сайта коллекция автоматически загружается из базы. Подтверждённые изменения отправляются автоматически с задержкой 650 мс. Настройки колеса тоже общие. Проверка ревизии защищает от случайной перезаписи более свежей версии с другого устройства. При конфликте пользователь выбирает версию; перед заменой создаётся локальная резервная копия.

Локальный кэш и очередь переживают перезагрузку страницы; при восстановлении сети отправка повторяется. Исходная коллекция браузера не подменяет общую. Не очищайте данные браузера до появления статуса «Сохранено в облаке».

Изначально перенесены 60 тайтлов из файла владельца anime-collection.json; колесо: classic, 10 секунд, 1 место. Экспорт текущей коллекции: «Сохранение» → «Скачать копию».

Схема общей таблицы в shared-schema.sql. Историческая схема аккаунтов cloud-schema.sql повторно не выполняется.

## Проверка

`node cloud-sync.test.cjs`

Тесты используют сервер в памяти и проверяют загрузку коллекции, сохранение, ревизии, конфликты, резервные копии и восстановление очереди.
